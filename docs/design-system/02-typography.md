# Typography

Southline retains its existing type families and scale: Cormorant Garamond for editorial display text and Inter for interface/body text.

| Role | Family | Color |
| --- | --- | --- |
| Page and section heading | Display | `primary` |
| Body copy | Body | `secondary` |
| Navigation and links | Body | `secondary` |
| Eyebrow on light | Body, uppercase, tracked | `accent-gold-text` |
| Eyebrow on dark/photo | Body, uppercase, tracked | `accent-gold` |
| Helper and metadata | Body | `text-muted` |
| Dark-surface copy | Body | `on-dark` / `on-dark-muted` |

Gold is not used for paragraphs or helper text. Mobile body copy remains at least 14px, with primary content generally 16px or larger.
