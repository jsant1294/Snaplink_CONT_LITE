# Southline Living Design System

This refactor unifies Southline Living's public marketplace UI around a warm, editorial residential palette without changing layout, component structure, routes, data, or behavior.

## Principles

- Charcoal headlines and primary content
- Forest green body copy, navigation, and links
- Champagne gold for emphasis, controls, and dark-background eyebrows
- Ivory pages, linen surfaces, and white raised cards
- Deep forest actions and footer surfaces
- Semantic tokens in reusable UI; no raw color values in public Southline components

SnapLink's dark product/dashboard palette remains intentionally separate and unchanged.

## Scope

Updated the homepage, search/results, professional cards, categories and ideas, homes, rentals, agent directory and profile wrapper, forms, header, footer, and shared Southline content sections. Business logic and protected dashboards were excluded.
