# Component Mapping

| Component/surface | Token treatment |
| --- | --- |
| Header | Ivory page, forest navigation, charcoal wordmark, semantic focus rings |
| Hero | Deep forest image overlay, white/linen copy, gold primary action, improved input contrast |
| Search/results | Raised search input, forest filters/actions, readable empty states |
| Professional cards | White raised surface, stone border, stronger overlay badges, forest primary CTA |
| Home service/category cards | Linen/raised surfaces, charcoal titles, forest copy, consistent borders |
| Homes/rentals | Ivory page, linen cards, forest actions, semantic photo overlays |
| Forms | Charcoal input text, muted placeholders, stone borders, gold focus, brick errors |
| Footer | Deep forest surface, white/linen copy, gold headings and clear hover states |

Reusable button primitives are available as `southline-btn-primary`, `southline-btn-secondary`, `southline-btn-outline`, and `southline-btn-ghost`. Form primitives remain `southline-input`, `southline-select`, `southline-textarea`, `southline-label`, `southline-help`, and state text classes.

Marketplace cards use `marketplace-card`, `marketplace-card-media`, and `marketplace-card-body`. Card media uses a consistent 4:3 ratio. Portraits use `marketplace-image-portrait` with a face-safe upper-center focal point; property, contractor, and construction images use `marketplace-image-project` with a center-bottom focal point. Metadata uses the ivory-and-forest `marketplace-chip` treatment.

The page canvas and structural section bands use two related warm architectural grays. Navigation, forms, chips, and marketplace cards use the raised ivory surface, creating hierarchy through borders and elevation rather than beige fills or heavy dark backgrounds.
