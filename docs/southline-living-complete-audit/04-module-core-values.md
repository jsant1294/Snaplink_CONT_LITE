# Module Core Values

| Module | What it does | Primary user | Problem solved | Core value statement | Commercial outcome | Customer-facing promise |
| --- | --- | --- | --- | --- | --- | --- |
| Homepage and marketing | Renders a public marketplace page with content blocks and CTAs | homeowner, contractor | Helps visitors understand the platform and find relevant next steps | This module helps the user discover the platform so they can quickly find local professionals or services | discovery, trust | Southline Living offers a public marketplace for local home services and real-estate-related discovery. |
| Booking flow | Captures project details and creates a lead for a chosen contractor | homeowner, contractor | Converts interest into a managed lead | This module helps the homeowner start a project request so they can connect with a professional quickly | lead generation, booking | Homeowners can request a consultation and send project details directly to a professional. |
| Contractor lead board | Shows incoming leads and supports status updates | contractor, operator | Gives professionals a simple workspace for managing leads | This module helps the professional manage leads so they can respond faster | lead conversion, operations | Contractors can receive and organize project leads in one workspace. |
| Module entitlements | Enables or disables paid modules per contractor | operator, administrator | Controls rollout and monetization of premium features | This module helps the operator manage product access so they can safely gate premium modules | upsell, platform retention | Operators can enable premium modules for selected contractors. |
| Flipbooks | Supports a multi-page self-service brochure experience | contractor | Lets a contractor share a branded story or project portfolio | This module helps the contractor tell their story so they can present their business more effectively | trust, reputation | Contractors can publish a branded Flipbook experience for their business. |
| Mini campaigns | Supports a single-page promo experience | contractor | Gives contractors a quick promotional surface | This module helps the contractor promote a service so they can attract new attention | lead generation, campaign potential | Contractors can publish a simple campaign page tied to their services. |
| Invoices | Supports invoice creation and Stripe-based flows | contractor | Helps professionals collect payment-related workflow | This module helps the contractor manage invoice workflows so they can move from job completion to billing | revenue collection | Contractors can create and manage invoice workflows. |
| Money | Supports financial tracking and tax-related features | contractor | Helps professionals manage business finances | This module helps the contractor organize financial records so they can run their business more efficiently | time savings, operations | Contractors can use financial tools for business tracking. |
| Real-estate CRM | Supports agents and brokerages with property, lead, transaction, and communication workflows | real estate agent, brokerage | Gives agents/brokerages a central operations workspace | This module helps the real-estate team manage transactions so they can operate more efficiently | operations, business intelligence | The platform includes operational tools for real-estate workflows. |
