# Product Roadmap

## Phase 1: validate the lead-generation core

- Finalize the contractor profile publishing flow.
- Polish the booking and lead intake journey.
- Improve the contractor workspace experience.
- Add simple onboarding and setup guidance.

## Phase 2: strengthen monetization

- Add a first paid professional plan.
- Make campaign and Flipbook add-ons more obvious and easier to set up.
- Add clearer plan limits and entitlements.

## Phase 3: expand the public marketplace

- Improve discoverability, search, and filtering.
- Add more rich profile and service data.
- Improve trust and social proof.

## Phase 4: deepen the real-estate layer

- Make transaction and lead workflows more seamless.
- Add stronger agent and brokerage onboarding.
- Improve data consistency across the CRM and public-facing pages.

## Phase 5: improve platform cohesion

- Reduce feature fragmentation between Southline, SnapLink, and real-estate modules.
- Clarify data ownership and module dependencies.
- Create a tighter shared identity and role model.
