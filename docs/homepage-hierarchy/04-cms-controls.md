# CMS Controls

The Sections tab controls Featured Rentals and Testimonials in addition to all existing homepage gates. Both default visible so legacy settings preserve live behavior through the existing default merge.

The Rentals & Getaways tab controls:

- English and Spanish eyebrow
- English and Spanish headline
- English and Spanish description
- English and Spanish CTA
- Maximum card count (1–4)
- Optional comma-separated rental IDs for manual priority

Both JSON and Postgres settings readers deep-merge the rental object and selected IDs. No migration is required.
