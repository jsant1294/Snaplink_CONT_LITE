# Mobile and Visual Treatment

Featured Rentals reuses the semantic design system and marketplace primitives:

- warm architectural-gray page canvas
- soft-ivory elevated cards
- architectural-stone borders
- charcoal headings
- forest-green copy and actions
- gold limited to the eyebrow accent
- consistent 4:3 imagery with center-bottom property focal positioning

The grid moves from one column to two and then three without changing card information hierarchy. Existing 44px shared action styles remain in effect.
