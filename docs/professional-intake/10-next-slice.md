# Next Slice

Deferred, in rough priority order:

1. **Apply the migration.** `drizzle/0023_professional_intake_sessions.sql` is generated, additive-only (single `CREATE TABLE` + one index, verified by test), and not yet applied. Run `npm run db:push` when ready — this immediately resolves the one `test:schema-drift` failure documented in `09-test-results.md`.
2. **Professional self-service entry point.** This repo's admin surfaces (`ProfessionalCatalogPanel`, `AgentProfilesPanel`) now both link to `/southline/admin/intake/{ownerType}/{ownerId}` for the operator. There is no equivalent self-service entry point for the professional themselves: contractor profile fields are operator-only by explicit product design (confirmed in `app/api/contractor/profiles/route.ts`'s PATCH handler — "a contractor never edits their own listing"), and an agent's self-service workspace lives in the separate `snaplink-lite 3` product, not in this repo. Building a professional-facing entry point would mean either changing the contractor edit-ownership model (out of scope) or adding a route to a different repo — a genuinely separate slice.
3. **Headless click-through verification.** No browser automation tooling is available in this environment (a recurring, previously-documented limitation in this session). The wizard/review UI (`IntakeConsole.tsx`) was verified via `tsc`/`build` and by reading the rendered route list, not by driving it in a browser.
4. **Richer image handling in the wizard.** `IntakeQuestion.type === "image"` currently renders a placeholder note in `IntakeConsole.tsx` pointing at the existing profile edit panel rather than an inline uploader — the upload API route (`app/api/professional-intake/upload/route.ts`) exists and is tested, but wiring a drag-and-drop UI onto it was deprioritized in favor of the engine/mapping/apply correctness this task's checklist emphasized.
5. **Session archiving UI.** `archived` is a modeled status (and the store supports it) but no route currently transitions a session into it — useful for an operator who wants to discard a stale draft and let the professional start fresh without waiting for it to reach `applied`.
6. **Bulk/CSV intake** for operators onboarding many professionals at once was explicitly out of scope for this pass (the spec describes one-at-a-time guided intake) and is a reasonable larger follow-up if onboarding volume grows.
